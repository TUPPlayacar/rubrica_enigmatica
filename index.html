Instrumento de Evaluación

Excelente (4 pts): Utiliza correctamente etiquetas semánticas HTML5 y estructura organizada.
Bueno (3 pts): Presenta estructura adecuada con mínimos errores.
Satisfactorio (2 pts): Existen errores de organización o uso limitado de etiquetas semánticas.
Insuficiente (1 pt): Estructura incorrecta o desordenada.
Excelente (4 pts): Diseño atractivo, consistente, responsive y profesional.
Bueno (3 pts): Diseño adecuado con pocos detalles de mejora.
Satisfactorio (2 pts): Diseño básico con problemas de presentación.
Insuficiente (1 pt): Diseño deficiente o sin estilos adecuados.
Excelente (4 pts): Implementa correctamente interacciones y funcionalidades dinámicas.
Bueno (3 pts): Funcionalidades operan con pequeños errores.
Satisfactorio (2 pts): Funcionalidades limitadas o incompletas.
Insuficiente (1 pt): No implementa JavaScript o presenta fallos graves.
Excelente (4 pts): Se adapta perfectamente a diferentes dispositivos.
Bueno (3 pts): Se adapta correctamente con ligeros detalles.
Satisfactorio (2 pts): Adaptación parcial a dispositivos móviles.
Insuficiente (1 pt): No es responsive.
Excelente (4 pts): Navegación intuitiva y excelente experiencia de usuario.
Bueno (3 pts): Navegación clara con pocos inconvenientes.
Satisfactorio (2 pts): Navegación funcional pero confusa en algunos apartados.
Insuficiente (1 pt): Navegación complicada o inoperante.
Excelente (4 pts): Código limpio, comentado y bien estructurado.
Bueno (3 pts): Código organizado con algunos comentarios.
Satisfactorio (2 pts): Organización regular y pocos comentarios.
Insuficiente (1 pt): Código desordenado y difícil de interpretar.
Excelente (4 pts): Integra elementos originales e innovadores.
Bueno (3 pts): Presenta elementos creativos moderados.
Satisfactorio (2 pts): Diseño convencional.
Insuficiente (1 pt): Ausencia de creatividad.
Excelente (4 pts): Entrega completa, puntual y con documentación adecuada.
Bueno (3 pts): Entrega completa con detalles menores.
Satisfactorio (2 pts): Entrega incompleta o documentación limitada.
Insuficiente (1 pt): No cumple con los requisitos de entrega.

Descripción de la actividad a desarrollar

Los estudiantes, asumirán el rol de Desarrolladores Frontend Junior. El reto consiste en diseñar, programar y desplegar una Página de Aterrizaje (Landing Page) completamente funcional, responsiva y optimizada para la conversión de un producto o servicio para una agencia de marketing digital.

El proyecto será desarrollado de manera individual durante el período del 2do. Parcial (del 05 al 29 de Mayo).

La rúbrica será utilizada durante la presentación y revisión del proyecto final. El docente evaluará cada criterio observando tanto el producto terminado como el código fuente desarrollado por el estudiante.

El estudiante conocerá previamente los criterios de evaluación para orientar su trabajo hacia el cumplimiento de los estándares establecidos. Una vez finalizada la evaluación, recibirá retroalimentación específica sobre sus fortalezas y áreas de mejora, favoreciendo así el aprendizaje y el desarrollo de competencias en programación web.
